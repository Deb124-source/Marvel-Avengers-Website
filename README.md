# 🛡️ Marvel Avengers Website

An immersive and visually dynamic Marvel-themed website inspired by the Avengers Universe.  
This project combines cinematic UI design, interactive animations, superhero showcases, villain battles, and multiverse-inspired effects to create a modern fan experience for Marvel lovers.

```bash
cd Marvel-Avengers-Website
```

## Run the Website

Open:

```bash
index.html
```

in your browser.
